# PAGENO Brand Assets

**PAGENO** is a personal money-management app built around a simple book/page metaphor.

**Tagline:** Your money, one page at a time.

## Brand idea
PAGENO treats finances like a personal book:
- Transactions → Entries
- Months → Pages
- Years → Volumes
- Savings goals → Bookmarks
- History → Previous pages

The name hints at “page no.” / page number while reading like a friendly product name.

## Personality
Warm, cute-not-childish, minimal, calm, editorial/notebook-like, slightly playful.
Rule: **90% calm, 10% silly.**

## Logo
The primary mark is a rounded book with a friendly face and orange bookmark/tab. The wordmark is a soft rounded lowercase treatment. For production, redraw as clean vector artwork rather than relying on raster crops.

## Palette

## Typography
Concept board: Poppins Rounded. For production, use a properly licensed rounded sans-serif such as Poppins, Nunito Sans, Manrope, or Inter. Redraw/customize the wordmark for consistency.

## UI tone
Good: “Your page is looking good.” / “A little something came in.” / “Still got some :)” / “Nothing happened here. Suspicious.”
Avoid generic fintech green/blue, dollar/coin imagery, neon gradients, and excessive mascot use.

## Asset note
These are AI-generated concept/prototype assets. Before public commercial launch, recreate the logo/mascot as clean vector artwork and run trademark/brand clearance for PAGENO in your target markets.
